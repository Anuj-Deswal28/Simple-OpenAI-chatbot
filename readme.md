this repo is created just for making a simple chat-bot with dynamic prompt, you can change role and behaviour of bot through prompt.py 


NOTE:-
[YOU ARE REQUIRED TO CREATE A ".env" FILE IN ROOT OF REPO BEFOR RUNNING "main.py" , it should contain "OPENAI_API_KEY :"<your openAI API key>""]

-> Run main.py through default Streamlit command i.e...
     streamlit rum main.py


-> Seprate Memory file is also present as "memory.txt" which will contain all chat-history 
-> An "template.json" file will auto created, which will consist of promt in json format when you run  "promt.py"
